## Principio de organizacao

O Super Tucan deve continuar simples para publicar e facil de testar por criancas. Toda evolucao precisa respeitar tres coisas:

1. leitura clara no celular;
2. desempenho leve no navegador;
3. universo brasileiro, colorido, engraçado e coerente.
